# Enterprise Visitor Management System

**Version:** 3.1.0 (Production Candidate)
**Status:** UI Complete & Production Ready

A premium, enterprise-grade Visitor Management System built with React, Vite, and TypeScript. It features a completely responsive Master Design System inspired by Microsoft 365, robust role-based workflows, and global security features.

## Key Features
- **Enterprise Design System**: Beautiful glassmorphic UI, responsive grids, and Recharts integration.
- **Role-Based Access**: Specialized dashboards for Admin, Security, Reception, and Employee.
- **Performance Optimized**: Global lazy loading, chunk optimization, and local storage caching.
- **Security Hardened**: Global error boundaries, explicit 404/403 states, and isolated context stores.
