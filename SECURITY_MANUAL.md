# Security Manual
## Enterprise Visitor Management System

This manual is for Security Personnel operating the Gate Operations Dashboard.

### Core Responsibilities
- **Check-In**: Validate visitors at the gate against pre-approved lists.
- **Check-Out**: Process exiting visitors. If a visitor is overdue, a warning badge will display.
- **Emergency Evacuation**: In the event of a fire or emergency, access the `Emergency Evacuation` tab to generate an instant printout of all **currently active** visitors on the premises.
- **Force Exit**: If a visitor leaves without scanning out, use the "Force Exit" feature and provide an audit reason. This will log a strict security intervention on the visitor's profile.

### Best Practices
- Always verify government ID for unfamiliar visitors.
- Never clear an emergency drill without checking the active roster.
